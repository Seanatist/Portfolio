Customer Churn Demo

Python · Scikit-learn · Streamlit · Telco dataset

Problem

Telecom businesses need early signal on which customers are likely to leave, based on profile and billing behavior — so retention teams can intervene.

Approach

  • Exploratory analysis and feature preparation on telco customer data
  • Classification model to predict churn probability
  • Notebook workflow plus a lightweight Streamlit scoring app

Result

A clear DS narrative from data → model → interactive demo, showing how churn risk can be operationalized beyond a notebook.
