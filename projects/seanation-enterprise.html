Productized BI · Synthetic demo

Seanation Enterprise Live Dashboard

Python · FastAPI · Pandas · Chart.js · python-pptx

Problem

Operations teams need a live view of growers, harvest lots, buyer settlement, and credit risk — not a static spreadsheet. The goal was a productized BI API with a usable UI and board-ready export.

Approach

  • Seeded synthetic universe (growers, field reps, buyers, lots, orders, credit)
  • In-memory store with refresh + scope filters (region, year, crop, rep, buyer)
  • KPI layer, region scorecard, explorers, and executive narrative
  • One-click PowerPoint board pack

Result

A self-contained FastAPI app recruiters can run locally: live dashboard, OpenAPI docs, searchable explorers, and PPT export — with an explicit synthetic-data disclaimer. Built as a personal portfolio demo; not affiliated with any employer.
