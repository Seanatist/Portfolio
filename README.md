## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
cd portfolio
python3 -m http.server 5173
```

Visit http://localhost:5173

## Deploy

Any static host works: GitHub Pages, Netlify, Cloudflare Pages, or Vercel (static).

## Note

Built as static HTML/CSS because Node.js was not available in this environment.
Can be migrated to Next.js later without changing content structure.
